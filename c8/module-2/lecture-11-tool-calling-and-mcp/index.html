Tool calling and MCP, part 2

In Lecture 10 you derived the reverse call on paper. Today you make one.

The lecture in one line

The model writes a request and stops. The server runs it. Write the tool card well and the model asks at the right moments; put the card next to the data and any app can use it. That is MCP.

01

Bring

  • Your Groq key, the one you made in Lecture 4. Lost it? Make a new one at console.groq.com/keys.
  • Your Practice set 1 sheet, for the last part.

Open the Tool Bench

02

The lecture

  1. Ask: nothing reaches the sheet
  2. Carry one tool call by hand
  3. Write the tool card against tests
  4. Switch the server on
  5. Move the card: MCP
  6. Do it with your own sheet

03

Done equals

Your tests marked before the first run, all passing. The downloaded log showing the call, the arguments, the result and the answer. And an MCP address for your own sheet that the second app can answer through.
