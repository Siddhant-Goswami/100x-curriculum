API as the second interface

Your UI has a face and no brain. The brain lives on another machine. This week you make the two talk, one request at a time.

Start todayAll in the browserDue before the Lecture 5 practical, Fri 9 Oct

The lecture in one line

Every request between two machines carries four things: an address, an action, a key, and a package in a format both sides agree on. Every reply carries two: a code and a package.

01

What we did in the lecture

Round ThreeThe machine answered every message with a code. Each code forced one part: one sender, then the address, the action, the key, the package.
The six partsRequest: address, action, key, package. Reply: code, package.
The CRUD quizCreate, Read, Update, Delete, spelled POST, GET, PUT or PATCH, DELETE. A Google search is a GET; asking an LLM is a POST, because it creates a new reply.
