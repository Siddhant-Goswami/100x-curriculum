RUNG 1A wire that is only on or off

Reveal what humans invented

Morse code1844 · Samuel Morse and Alfred Vail

A shared codebook of dots and dashes. The first public line ran from Washington to Baltimore on 24 May 1844. The message was "What hath God wrought."

Turn the codebook off and the same pulses still arrive. They just mean nothing. Both ends must hold the same codebook, or the message is noise.

This becamepackagethe idea of a shared code under every character you send

Common languageBoth sides agree on what each signal means.

RUNG 2No human at either end

Ask first

Morse needs a trained human at each end. What would a machine need instead?

Try it · type anything

Every character becomes a number, and every number becomes on and off.

Reveal what humans invented

ASCII1963 · American Standards Association, committee X3.4

A fixed number for every character, agreed by every machine. A is 65. Seven bits, so 128 characters. No operator needed: a machine reads the bits and knows the letter.

128 slots had no room for नमस्ते. UTF-8 (1992, Ken Thompson and Rob Pike) keeps ASCII as it is and uses more bytes for every other script. That is why A is still 65 today.

This becamepackageevery character inside it

Common languageA format machines agree on, with no human in the middle.

Reveal what humans invented

TCP/IP1974 paper · Vint Cerf and Bob Kahn · ARPANET switched over on 1 Jan 1983

IP gives every machine an address, like 203.0.113.7, and every packet carries it. TCP numbers the packets, confirms each one that arrives, and asks again for what is missing. That is how you know it arrived.

Neither one cares what is inside the packets. They only deliver.

ProtocolRules for delivery that ignore what is inside.

Reveal what humans invented

HTTP1989 to 1991 · Tim Berners-Lee at CERN · about 35 years ago

A request carries an action (the method), an address, headers written on the envelope, and a body inside it. A reply carries a status code and a body. Every API you call today still works this way.

HTTPS is HTTP inside a sealed envelope. Switch to http above and anyone between you and the machine can read your key. The S seals it. That was your DM in Round Three.

This becameactionkeycodethe key is a header, written on the envelope

ProtocolInput → Process → Output, across a wire.

RUNG 5Fifty companies, fifty words

Ask first

Company A calls it getDiagnosis, B calls it fetchDiag, C calls it retrieveDiagnosis. What goes wrong when you connect to 50 of them?

Try it · sort twelve names into four buckets

Tap a name, then tap the bucket it belongs in. Three companies already need twelve words.

Reveal what humans invented

REST2000 · Roy Fielding's PhD dissertation

Addresses are nouns: /diagnoses, /workflows/7. A handful of shared verbs act on them: Create, Read, Update, Delete. On the wire they are spelled POST, GET, PUT or PATCH, and DELETE. Learn four words once, and every REST API speaks them.

CRUD is a term from 1983. It comes back in Lecture 6, where a database does the same four things to a table.

This becameaddressaction/diagnoses plus CREATE

ProtocolAn agreement on how to use HTTP. Strictly a design style, not a protocol of its own.

Reveal what humans invented

    
JSON2001 · Douglas Crockford · standardised as ECMA-404 (2013) and RFC 8259 (2017)

    
Plain text: keys and values in curly braces, every key in double quotes. JSON is a format, not a language. A .docx opens in Word and in Google Docs because both agree on the file format. JSON works the same way: every programming language and every no-code tool reads it, which is why it became the web's default package format.
