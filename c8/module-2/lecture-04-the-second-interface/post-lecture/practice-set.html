02How It Works

  1. Open the Request Builder. Everything happens in that page. Nothing to install.
  2. Do the steps in order, 1 to 10. Each step ends with a checkpoint. Tick it when you have the result; ticks save on this device.

03Code Track and No-Code Track

Both tracks: every step, in the browser. The Request Builder sends real requests for you. You fill in the four parts and read the reply. That is the whole skill, whichever track you are on.

Code track, optional extra: run step 8 in Python. If you set up Python in Lecture 3, run the Python version of the Groq request shown in step 8. It becomes the body of your FastAPI route in Lecture 5.

No-code track: the same four boxes in any HTTP step. Every no-code tool that calls an API asks for the same things: URL for the address, Method for the action, a header named Authorization for the key, and a JSON body for the package. Each step in the Request Builder shows the mapping. In Lecture 5, Antigravity will ask you for the same parts.

04Deliverable 5: Design Your API

Use your Assignment 1 observation. If your hypothesis is not ready yet, use Aarav's workflow. Start from one question: what does your user do, and which of those actions would your app need another machine for?

Three boxes sit behind that table: UI → backend → Groq. The UI calls only the backend. The backend holds the Groq key and stores the data, because a page can do neither.

Check your table before you post

  • Every action is one of Create, Read, Update, Delete, spelled with the matching method.
  • Addresses are nouns (/workflows), not verbs (/getWorkflow).
  • At least one request calls a model.
  • No key sits in the UI box.
  • Each reply lists the success code and at least one failure code.

05Rules

  • Predict the code before you send. Write down the code you expect before every request in steps 4 to 6. Keep the prediction even when it is wrong; the wrong ones are where you learn.
  • Never paste a key in Discord. Not in a message, not in a screenshot, not in an AI chat. If a key leaks, revoke it and create a new one. See step 9.
  • Use your own Groq account. Groq's free limits apply per account, not per key: 30 requests a minute and 1,000 a day on openai/gpt-oss-120b. A shared account runs out for everyone at once.
  • Stuck for more than 20 minutes? Check Troubleshooting first. Then post in the Discord channel: the exact error and code, what you tried, and the request with the key masked.
