The key goes in a header: Authorization: Bearer aarav_…. The machine checks the parts in the order of the list: address, then action, then key, then package. The first part that fails is the only error you get.

4The Same Requests in a Terminal

Optional. curl sends a request from the terminal and prints the reply. It is already installed on Mac and on Windows 10 and 11.

Windows: two things first

In PowerShell, type curl.exe, not curl; plain curl can run a different PowerShell command. PowerShell also mangles JSON typed inside a command, so save each package in a small file and send the file with --data "@file.json". Or install Git for Windows and use Git Bash, where the Mac commands work as written.

Add -i after curl to see the status code and the reply headers as well as the package.

Terminal · POST httpbin
curl -X POST https://httpbin.org/post \
  -H "Content-Type: application/json" \

Save this as text.json in the folder your terminal is in:

The action is in the function name: requests.post. Passing json= turns the dictionary into JSON and adds Content-Type: application/json for you. os.environ reads the key from the environment, so it never sits in the file.

6Words You Will Meet

APIThe interface between two machines: the agreed way one asks and the other answers.
EndpointOne door of an API: an address plus the actions it takes. /aarav/diagnoses is one.
URLThe full address: the rules (https://), the machine, the path, and any query.
PathThe door on the machine: the part after the domain, such as /diagnoses.
Query stringExtra details on the address after a ?, such as ?text=hello. Spaces become %20.
MethodHow the action is spelled on the wire: GET, POST, PUT, PATCH, DELETE.
CRUDCreate, Read, Update, Delete: the four actions. Create is POST, Read is GET, Update is PUT or PATCH, Delete is DELETE.
HeaderA line written on the envelope, not inside the letter. The machine reads it without opening the package.
AuthorizationThe header that carries the key.
BearerThe word before the key. Whoever bears this key gets in.
BodyThe package inside the request or reply.
JSONA text format, not a language: keys and values in curly braces. Every language and tool can read it.
Status codeThe three-digit number at the top of every reply. It says what happened.
2xx · 4xx · 5xx2xx it worked. 4xx you sent something wrong. 5xx their machine failed.
RequestWhat you send: address, action, key, package.
ResponseWhat comes back: a code and a package.
Rate limitHow many requests an account may send per minute or day. Past it: 429.
CORSThe browser's rule that a page may only call another site if that site allows it.
HTTPSHTTP inside a sealed envelope. Nobody between you and the machine can read the key.
StreamA reply sent in many small pieces as it is written, so words appear one by one.
ModelThe program that reads text and writes text back. Here, gpt-oss-120b, running on Groq's machines.
Open-weightA model whose trained numbers are published, so anyone can run it. Groq serves many.
LPUGroq's own chip for running models fast. Groq with a q, not Grok.
BackendThe machine behind your UI. It holds the keys, calls the model, and will store the data.
