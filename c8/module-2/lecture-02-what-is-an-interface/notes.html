The first interface

An interface derived from a game the room lost twice, then tested on a phone call, a letter, a meme and ChatGPT. Read sections 03 to 05 slowly: everything after applies one idea. Come back to section 11 before the API lecture.

Fri 25 Sep 2026Instructor: Siddhant GoswamiBoth tracks

01One principle, three kinds of verification

  • A rule. Same input, same output. Build it with what already exists: code and no-code tools. Weeks 1 to 4.
  • Judgment. No rule, but you can extract the judgment and hand it to a stranger who then judges as well as you. That judgment can now go to an LLM.
  • Not at all. What Naval calls specific knowledge: what you do better than anyone and cannot pass on. A human stays in the loop, weeks 8 to 12.

03Round one: a hundred programmers, one machine, no smiley

Siddhant became a machine for two minutes. The goal: get him to draw a smiley on his whiteboard. Pasting an emoji or an image did not count.

  • Input. Instructions only from the Zoom chat.
  • Execution. One action per message, in the exact order messages arrive. Two people sending different actions: both run, in sequence.
  • No guessing. An unclear, incorrect or unknown instruction produces nothing.

More than 100 people failed. The room's diagnosis: no coordination, instructions not detailed enough, no one leading. Siddhant added the one nobody offered: no one asked the machine which language it understands.

When a deterministic machine fails, the fault is almost always on our side: an instruction we did not articulate, or a team that did not coordinate. Debugging is mostly finding which.

04Round two: a common language, still no smiley

  • An underspecified command. "Go to 0". The command took X and Y, with 0,0 at a corner Siddhant had chosen. Nobody asked where; someone could have probed with small coordinates until the cursor reached the toolbar.
  • Commands the machine never had. "Pick a pen" is English. "Circle R" is not a command either: "circle 5" draws a circle of radius 5. Three messages saying "circle" draw three identical circles.
  • Too many programmers. One machine taking orders from a hundred people does not finish the task.

05Two systems, and the bridge between them

The game, redrawn as two boxes. Two things were missing between them: a common language, which round two supplied, and a set of rules. The subtle failure: the rules covered only the machine.

The winning version: pick one point of contact. Everyone else sends suggestions to that person, and only they write in the chat. Go to 0,0; nothing happens; adjust; reach the toolbar; click; draw. The agreed rules are a protocol. Language plus protocol opens a channel that runs both ways. That bridge is an interface.

An interface is the boundary, bridge, or point of interaction where two separate systems, components, or entities meet and communicate.

06The phone call: the wire is not the interface

The room answered with parts: phone line, cable, network, signal, speaker, microphone. Fix the language (both speak German) and there are still rules: one says hello, the other replies, each works out why the other called. The hardware is needed. It is part of the interface, not the whole of it.

07The letter: find the two systems first

Answers: envelope, letter, address, stamp, PIN code, even a pigeon. The method: name the two systems before anything else. A letter goes from a sender to a receiver: two people, with pen and paper instead of a phone. Common language: say Hindi. Rules: envelope, address, post office, stamp, fee, wait. Every answer typed in chat is in there, as a component.

The one system doing all of it is the postal service. It sets the rules and runs the delivery. The postal service can be called an interface; the address never can.

08The meme as an interface

In the I, Robot scene Will Smith asks a robot why it is so often biased and wrong; it answers, because you built and trained me. The Drake template rejects a 50-page document and approves one meme. The answer is meme.

  • Common language: shared context. You laugh hardest if you have seen the scene.
  • Rules: the template's fixed panels. Accusation, mirror, realization; or rejection, approval.
  • Why it spreads. Richard Dawkins coined the word in The Selfish Gene: a unit of culture passed by imitation. It activates context the audience already has, so one image replaces an essay. Siddhant's claim: one of the highest-bandwidth cognitive interfaces ever invented.

09ChatGPT: the screen is the first interface

Answers ranged from natural language to "the entire screen". Method first: the two systems are a human and an LLM (software that must run on a machine). Input: the prompt. Output: the reply. Common language: English. Rules: recall the game, where one tool, the Zoom chat, received input and passed it across.

Software calls its customers users (software and drugs are the only two industries that do). The interface between a user and a machine, made of graphics you click, type into and touch, is a graphical user interface, now simply the user interface (UI). In ChatGPT, the whole screen is. This is the first interface.

10Behind the screen: the Inspect tool

Most people think the screen is all of ChatGPT. It is only the part that talks to you. You do not need to read the Network tab yet. The point: pressing send makes your machine send information on your behalf, at several levels: you to machine, machine to browser, browser to internet provider, and on to ChatGPT.

If you cannot identify the systems behind an existing app, you cannot build one like it.

A user never touches the UI directly. A keystroke becomes an electrical signal; the operating system lets you use the hardware; the machine opens the browser; the browser fetches the app; only then is there a UI. This applies to every app on the internet.

12The second machine, and the second interface

Typing chatgpt.com starts a trip. Your internet provider confirms a connection, then the name becomes an IP address: numbers, the most precise language machines share. It is the address on the envelope, and it leads to another machine, owned by OpenAI, listening for requests. The full routing: how DNS works.

Siddhant's is a MacBook Pro; OpenAI's might run Linux on NVIDIA hardware. Neither understands the other. The room named the bridge: the API, Application Programming Interface, the machine-to-machine interface.

13HTML, HTTP, and the rules the room never wrote

Every machine, from laptops to AirPods, shares one language: binary. High-level languages sit on top and map down to it. Before the internet, every machine had its own language, so someone had to agree on a common one.

For the web that was Tim Berners-Lee at CERN. He built HTML (Hypertext Markup Language) as the common language for structuring pages, and HTTP (Hypertext Transfer Protocol) as the rules for moving them. Hypertext links to another page; linking every page to every other became the world wide web.

In the Network tab, the first entry after a refresh is a request (URL, method, status code) and a response, originally always an HTML page. One rule is built in: every request stands on its own, so the receiver needs no backstory. That is the protocol the room never wrote: what to send, who sends it, in what form, and how the response is read.

15From the Q&A

  • Do layers 1 and 2 matter if I only build the UI? (Neha Agrawal) Sometimes not; often yes. For deeper hardware control, they decide what your UI can and cannot do.
  • Is the common language the interface? (Swasti) No. Establishing it is step one of building one.
  • Where do binary and Python come in? (Saiteja) Binary is the one language a macOS and a Linux machine are guaranteed to share. Assembly maps a handful of commands to zeros and ones, like the round two list; each language above abstracts further, up to English.
  • Do I need HTML and CSS for the code track? (Mohit) No. Python throughout, with libraries that translate it into HTML, CSS and JavaScript. The one exception is SQL, in the database lecture.
  • How do I find 10 people for my manual MVP? (Hardik) Finding them is the exercise. If you cannot find 5 to 10 people for whom the problem is painful, pick a different observation.
  • My hypothesis keeps changing. Good. If it is not changing, you are not learning. Log each change and its cause; the log is part of a good Assignment 1.

Keep this

An interface is not a wire, a language, or a screen. It is whatever lets two systems that do not understand each other meet and communicate, and you build one from two things: a common language, and a set of rules both sides follow. The UI is the first interface you meet: between a human and a machine. Behind it sit more systems (hardware, operating system, browser), every pair joined by its own interface.
