01Why This Exercise Exists

A passenger enjoys the comfort of a car. A driver understands its controls and knows what to do when things go wrong.

Comfort without understanding comes at the cost of control.

In software, SDKs, libraries, no-code/vibe-coding tools are like comfortable passenger seats. They make the journey easier by hiding the machinery underneath.

But hidden machinery doesn't disappear.

When something breaks, what you understand determines what you can fix.

To drive software machines, understand its controls: APIs, endpoints, authentication, requests, and responses.

Use abstractions for comfort. Build understanding for control.

A 200 proves the call worked. Only your verifier proves the reply helps.

What each code means here




200Groq understood you and sent a reply. It does not mean the reply helps anyone: that is section 05.


400The package is wrong: broken JSON or a missing field.


401The key is missing, mistyped, or sent without Bearer.


404The model named in the package does not exist, or the address is wrong. Read the message: it says which.


429Too many requests this minute on your account. Wait and send again.


5xxTheir machine, not yours. Try again later.




Status code says whose fault; the message says what. Try the fix the error points to before pasting anything into an LLM. More in Troubleshooting.

06Rules of the Build


Predict before you run.
Every request in the prediction log gets its expected status code written down first. Include at least two deliberate failures: a wrong model name and a missing or wrong key. Record what each actually returned.


Read the error before you ask.
Status code says whose fault; the message says what. Try the fix the error points to before pasting anything into an LLM.


Minimum path.
No extra parameters, no chat history handling, no changed interface, no renamed functions. The diff from the echo app should be the process and nothing else.


Keys never in code or screenshots.
Set it in the terminal, never in the file. Blur the key in every image you post. If a key leaks, revoke it and create a new one: Keys.


Stay inside the free tier.
Groq allows 30 requests per minute. You will not need more.


LLM help: hints and debugging yes; generating the solution no.
Think for the first minute on your own. Pasting this brief in and copying the code out defeats the exercise; the code is short enough that writing it is the learning.
