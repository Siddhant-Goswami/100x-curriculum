Replay before you render

One real user. Ten golden pairs. A chat running on your own machine.

Follows Lecture 3, Sat 26 Sep 2026.Post in the code track channel.

The brief

Write a spec for one real user with 10 golden pairs and a numeric verifier, replay one pair to derive the interface, then run that interface locally in Gradio and compare it with a vibe-coded version.

01Why this exists

Aarav's status report was a proxy. The skill is not Gradio; it is deriving an interface from an output. In the lecture, 17 people voted for a search box and one follow-up question overturned it (notes, section 09). Run the same replay on your own user, where nobody hands you the answer.

02Track A: your own problem (preferred) 0 of 6 ready

03Track B: Aarav's documents

Use the discovery document and the golden pairs. Run the same loop with Aarav as the user and pair 1 (the Friday status report, about 3 hours) as your anchor. Two changes stop this from being a copy:

  • Write 3 new pairs yourself for other repeated tasks Aarav could plausibly have, each with its own verifier.
  • Replay a different follow-up, not "What does backtesting mean?". If your replay still lands on chat, say why in your own words.

04Rules of the build

  • Gradio only. No deployment yet; the office hour takes your local app to a link.
  • Predict before you run. Write down your interface pick before the replay, and the error you expect before your first python app.py. Keep both, even when wrong.
  • Docs before chatbots. Learn gr.Interface and gr.ChatInterface from the Gradio documentation. Ask an LLM only after you have read the relevant page.
  • AI is allowed, blind pasting is not. You must be able to point at the input, the process and the output in every line of your first-principles version.
  • Log every error. Message, cause, fix. Python not found and Gradio not installed count. The office hour reviews this log.
  • Mask, do not withhold. Replace proprietary numbers with percentages or X, Y, Z, but share the spec.

The starting template:

import gradio as gr

def respond(message, history):
    return "You typed: " + message

gr.ChatInterface(fn=respond).launch()
