03The principles

Each one is found in a scene. Remember these and you can rebuild most of the rest.

  1. Fast memory forgets. Lasting memory lags.
  2. A little data says how to read the rest.
  3. Faster reading means a second copy.
  4. Record the change in one place before changing anything else.
  5. Keep one original. Every copy can be thrown away and remade.
  6. A count only knows what it saw. A pattern can guess what it didn't.
  7. Learning is reducing mistakes toward a goal, with feedback from every attempt.
  8. Meaning comes from company. Every token listens to the ones before it, and becomes what it hears.
  9. A machine learns what you can check. The easier the check, the faster it learns.
  10. A machine learns the check you wrote, not the goal you meant.
