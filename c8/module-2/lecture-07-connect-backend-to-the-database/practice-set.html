05Rules

  • One function first. Not the UI, not storage. If it does not run from the terminal, nothing above it will.
  • Keys live in environment variables. In the terminal on your laptop, in the dashboard on Vercel. Never in the file, never in a screenshot, never hardcoded to make a 500 go away.
  • Predict, then run. Write the status code you expect before each call.
  • Thin API. JSON in, JSON out. Convert to sheets or files on the user's device, not on the server.
  • Mock the LLM if you need to. Build the deterministic path from your golden pair first. Add the model call last.
  • LLM help: terminal chores and diagnosis, yes. Writing your function, no. Read every command it runs.
  • Public repository. Commit after each step, push when the step works.
