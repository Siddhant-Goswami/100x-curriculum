Give your row a tool

Due before Lecture 13, Fri 20 Nov 2026.

The brief

Make one failing case pass by writing a tool. Then build a tool for the row you tested in Practice set 1, with the cases written first. Start from the c8-tools repo.

01Warm-up: make case 6 pass

python 06_verify.py fails on "Which lectures on the code track use Supabase?" The sheet says lectures 7 and 8. Neither tool can answer it in one call. The notes show why.

  1. In tools.py, write a function that takes a tool name and a track, and returns the lectures that use it.
  2. Write its card. Say when to use it and when get_lecture is the better one.
  3. Add the function to FUNCTIONS and the card to CARDS.
  4. Run the verifier until case 6 passes. The cases that passed before must still pass.

02Your row: write the cases first

Open your Practice set 1 sheet at the row you tested in step 04. Beside it you wrote what the model was missing. That is what your tool fetches.

  1. Name the source. A CSV file, a Supabase table, or an API you already called in this course.
  2. Write three cases in a copy of 06_verify.py, before any other code: one question that should call your tool, one with a tricky input, and one the model should answer itself.
  3. Work out each answer by hand from the source and put it in answer_has.

03Build the tool

  1. The function. It checks its input and returns a dictionary. Run it alone first, as in 03_function.py.
  2. The card. Name, description, parameters, required, types.
  3. Run the loop with 05_loop.py and read the record.
  4. Run your cases. When one fails, decide which it is: the function, the card, missing context, or a part only a person can judge.

04Give it an address

  1. Add your function to 08_mcp_server.py with @mcp.tool, a docstring and type hints.
  2. Run the server, then ask your question through 09_second_app.py.
  3. Write one line: does your task need MCP? Use the table in section 13.

05Share it

  • Your cases and the verifier's output.
  • One line of log.jsonl: the call, the arguments, the result, the answer.
  • Your one line on MCP.

Once you're done, share it on the Discord. We go through them in the office hour.
