Practice set 3 · after Lecture 12 · Code track

Write the code behind the bench

Due before Lecture 13, Fri 20 Nov 2026.

The brief

On the Tool Bench you pressed buttons. Now write the code behind each one, on the same course sheet, then put the tool on the internet. Every step is in the c8-tools repo.

01What you write

On the benchIn the repo
The sheetget_lecture(number)Given
The modelask_model(messages, tools)Given
Your serverThe bottom of tool_call.pyPart 1
The sheet's servermcp_server.pyPart 2

Set up first: fork the repo, install, add your Groq key.

02Part 1: the tool call

In tool_call.py. Run it after every step.

  1. Ask without a card
  2. Write the card
  3. Run the request
  4. Hand the row back
  5. Let your code carry it
  6. Test the card

Done when the same file answers a lecture question from the sheet and "What is an API?" on its own.

03Part 2: the MCP server

In mcp_server.py.

  1. Move the function
  2. Write the card into the function
  3. Switch it on
  4. Put it on the internet
  5. Call it from anywhere

Done when fastmcp call returns the Lecture 12 row from your address on the internet.

04Now your own data

Do it once more with your own Google Sheet, a CSV file, a Supabase table, or an API from this course: your function, your card, your five questions.

05Submit it

  • The link to your fork, with the five-question table filled in.
  • Your deployed address.

Once you're done, submit it on the LMS. We go through them in the office hour.
