What to hand to an agent

An agent is fast, cheap and sometimes wrong. Four questions follow from that one fact, each built on the answer before it.

01Start from one fact

The agent will sometimes be wrong. So handing it a task pays only when four things are true, and each one only matters once the one before it holds.

  1. The time is real. You can only save time you measured.
  2. The agent can do it. Without you supplying the judgment, the inputs or the check.
  3. A mistake is cheap. How far it runs alone depends on what a wrong run costs.
  4. It rarely makes one. Proved on your own tasks, not on a demo.

Each section answers one and fills one box. The running example: an engagement manager at a Bengaluru consulting firm, eight years in, on Google Workspace, with travel and a home loan on the side.

No saving can be shown without a baseline, so nothing is decided before one real week is logged. Write the number when the task ends; estimate nothing.

04Level: what does a mistake cost?

Seven tasks an agent can do. It will still get some wrong, so how far it runs alone follows from what a wrong run costs. Two dials set that:

  • Undo. Can you reverse it in one step with nobody outside noticing? A draft, yes. A sent email, a booking, a payment, no.
  • Blast radius. Who does a wrong action touch? A note to yourself is small. A client, money or someone else's numbers is large.

The dials give three levels. Autonomous: it does and commits. Accelerated: it does the work and stops before the step that commits. Assisted: it helps, you do it.

The Verifier's Rule caps it. Whoever approves must check faster than they could redo. A task not checkable in two minutes cannot be Autonomous, even in the green corner.

05Trust: does it rarely fail?

The level is a ceiling, not a start. Every task begins Accelerated and moves up only when the agent proves it on your own work.

  1. Fix the test set from your log before testing. For the consultant: 3 meeting prep packs from real threads, 3 research briefs with a known answer, 3 triage runs on a frozen inbox, 2 status emails, 2 monitors run for a week, 2 travel searches with a known cheapest option.
  2. Same prompt, connectors and tier for every agent. One attempt per task.
  3. Check the output in the tool you will use. A sheet that passes its own checks and breaks in Sheets is a fail.
  4. 8 of 10 unlocks Autonomous for that task type only.

A test cannot show multi-week reliability or real hours saved. Keep the step 1 log for a month after adoption.

07Tools: which agent, as of 18 Oct 2026

The framework names no agent. This section does, and it dates fast: re-check every 60 days. Evidence grades: Tested is a published hands-on run with a score, Reported is press or one reviewer, Documented is the vendor's word. None of these has been run against the 8-of-10 bar yet.

  1. Drop any agent you cannot use where you are. A VPN does not count.
  2. Drop any whose connectors do not reach the task's inputs.
  3. Pick Tested evidence on the closest task over Reported over Documented.
  4. On a tie, the smaller permission scope, then the lower cost.

Keep this

Measure a week before deciding anything. Screen out judgments, unreachable inputs and anything you cannot check in two minutes. Set the ceiling by undo and blast radius, never by how smart the agent seems. Start everything Accelerated and let nothing run alone until it lands 8 of 10 on your own tasks.
